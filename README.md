# מהירות רשת

מד תעבורה לגלקסי. האפליקציה מציגה את קצב ההורדה וההעלאה של הרשת הפעילה, ושם את המספר כסמל בשורת המצב.

זו לא בדיקת מהירות מול שרת. כששום דבר לא זז, המספר קרוב לאפס. ברגע שמתחילה הורדה או העלאה, הסמל מתעדכן כל שתי שניות.

המדידה עצמה נשארת בטלפון. חיבור לאינטרנט משמש רק לבדיקת עדכון גרסה, מול הקובץ הציבורי `dist/version.json` בריפו בגיטהאב.

## איפה הסמל מופיע

אנדרואיד לא נותן לאפליקציה רגילה לצייר ליד השעון, ה-Wi-Fi או הסוללה. המספר נכנס **לאזור סמלי ההתראות** בשורה העליונה. משיכה של הלוח למטה מציגה את שני הכיוונים בטקסט ברור, למשל `↓ 1.50 MB/s    ↑ 120 KB/s`.

ב-One UI מוצגים בדרך כלל עד שלושה סמלי התראות. אם השורה מלאה, הסמל עלול להידחק.

## התקנה על Galaxy S26

1. מעתיקים את `dist/netstrip.apk` לטלפון.
2. פותחים את הקובץ ומאשרים התקנה מהמקור הזה. אם בעתיד מתקינים גרסה שנבנתה במחשב אחר, מוחקים קודם את האפליקציה, כי החתימה לא תתאים.
3. פותחים **מהירות רשת**.
4. מדליקים **הצגה בשורת המצב** ומאשרים התראות.
5. בהגדרות האפליקציה, בשימוש בסוללה, בוחרים **ללא הגבלה**. בלי זה סמסונג עלולה להקפיא את הסמל.
6. בהגדרות הטלפון: התראות → הגדרות מתקדמות, ולוודא ששורת המצב מציגה סמלים ולא רק מספר.

אפשר גם להוסיף אריח בהגדרות המהירות: מושכים את לוח ההתראות עד הסוף, עורכים את הכפתורים, וגוררים את **מהירות רשת**.

המהירות היא של כל התעבורה שנכנסת ויוצאת מהמכשיר, גם ב-Wi-Fi וגם בסלולר. הסמל מציג הורדה והעלאה יחד. האפליקציה עולה עם הדלקת המכשיר. הגרף יכול להציג את הדקה האחרונה או את השעה האחרונה.

## בנייה מחדש

צריך JDK 17 ומעלה ו-Android SDK עם `platforms;android-35` ו-`build-tools;35.0.0`.

```bash
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew :core:test :app:assembleDebug
```

ה-APK נוצר ב-`app/build/outputs/apk/debug/app-debug.apk`.
